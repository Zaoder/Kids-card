# Ζωάκια (Kids Card)

Εφαρμογή Android για μικρά παιδιά (1–3 ετών): πατάς ένα ζωάκι, ακούς το όνομά του και μετά τη φωνή του.

- 16 ζώα σε μεγάλες, χρωματιστές κάρτες
- Όνομα με την ελληνική φωνή του κινητού, μετά αληθινός ήχος του ζώου
- Χωρίς διαφημίσεις, χωρίς internet, χωρίς κουμπιά που μπερδεύουν· το «πίσω» είναι απενεργοποιημένο
- Παρατεταμένο πάτημα (2 δευτ.) στον τίτλο: πληροφορίες για γονείς και credits ήχων

Το APK χτίζεται αυτόματα και ανεβαίνει στα **Releases**. Οι ήχοι κατεβαίνουν από το Wikimedia Commons με το workflow «Fetch sounds» (βλ. `tools/fetch_sounds.py` και `CREDITS.md`).
